SUPER‑GIANT

SUPER‑GIANT is a purpose‑built, decoder‑only transformer written in JAX. Version 1 (the current stable branch) focuses on speed and research‑friendliness rather than massive scale.

Key Features

  • Flash Attention implemented with the cuDNN 12 primitives wrapped for JAX.
  • Full‑dimensional KV cache for low‑latency autoregressive inference (plans for low‑rank cache reconstruction à la DeepSeek MLA are tracked for v2).
  • Optax‑based training loop with built‑in gradient accumulation and mixed precision.
  • Self‑contained train.py, generate.py, and prepare_dataset.py scripts – each exposes a rich --help.
  • Synthetic‑data pipeline that can query OpenAI endpoints or any local model that speaks the OpenAI API spec (e.g. Ollama).
  • Optional Flask‑based server / ui pair so you can talk to the model from a browser instead of SSH.

Directory Layout (v1)

v1/
├─ model/                # Core model definition (Flax Module), loss & train loop helpers
├─ data/                 # Synthetic‑data generation pipeline
├─ server/               # REST + WebSocket gateway, GPU‑bound
├─ ui/                   # Simple React SPA talking to server/
└─ terra/                # Thin Terraform wrapper for RunPod GPU nodes

Example: Start a small training run

python -m v1.model.train \
  --dataset=./data/tiny_stories.jsonl \
  --model_dim=512 \
  --n_layers=8 \
  --n_heads=8 \
  --save_dir=./checkpoints/run1 \
  --max_steps=100_000

Example: Generate text with a checkpoint

python -m v1.model.generate \
  --ckpt=./checkpoints/run1/step_100000 \
  --prompt="One sunny day," \
  --max_tokens=200

The v0/ folder contains the very first prototype and is kept for posterity; you probably only want to look at v1/ unless you are interested in how the architecture evolved. Planned experimental branches (e.g. v2‑moe) live side‑by‑side.
