LADA – Local AI Developer Assistant

LADA is a Flask service that turns a local (or remote) LLM into a pair‑programmer à la Claude Code or OpenAI Codex – but with zero cloud dependency. Everything runs on your own GPU / CPU, so your code never leaves the machine.

High‑level Workflow

  1. The browser UI shows two panels: Chat and an optional Terminal.
  2. Every user message is first read by a lightweight router model which decides whether the request is trivial or needs heavy reasoning.
  3. Simple requests are answered directly by a coder model (faster, cheaper).
  4. For complex instructions the router forwards the full history to the Orchestrator model.
    The Orchestrator can:
    • Break the task into atomic subtasks (planning).
    • Spawn multiple coder instances that work in parallel.
    • Iterate until all subtasks are solved, then merge the results.
  5. Both coder and orchestrator can be swapped between providers:
    • Any Ollama‑hosted model (llama3, phi3, etc.)
    • Or remote OpenAI models such as gpt‑4o (handy fallback).

Server Anatomy

LADA/
├─ app.py            # 400+ LOC – the single Flask application
├─ static/           # JS & CSS assets for the frontend
└─ templates/        # Jinja2 templates (chat, terminal, layout)

The bulk of the logic lives in app.py – it multiplexes requests to models, streams partial responses back to the browser via Server‑Sent Events, and proxies shell commands when the user toggles the terminal.
