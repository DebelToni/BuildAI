Everyday Usage

Talking to SUPER‑GIANT

  • python -m v1.model.generate --ckpt=... --prompt="Hello" – one‑shot generation to stdout.
  • curl -X POST http://localhost:8008/api/v1/completions -d '{"prompt":"hello"}' – REST style.

Using LADA as your code assistant

  1. Start the server: python app.py --model ollama:llama3:8b
  2. Open the browser, type a coding question, wait for the router to decide.
  3. Toggle the terminal (Ctrl+`) to run shell commands inline.

Generating synthetic training data

python -m v1.data.generate_synthetic \
  --teacher ollama:llama3 \
  --dataset tiny_stories \
  --n_prompts 1_000_000 \
  --temperature 0.8
