Welcome to BuildAI

BuildAI is an open‑source framework for building and experimenting with custom large language models (LLMs) and the developer tooling that surrounds them.

The project is a meta‑repository that stitches together two core sub‑projects (pulled in as Git submodules):

  1. SUPER‑GIANT – a JAX‑based LLM implementation that you can train from scratch, fine‑tune, or run for inference.
  2. LADA – the Local AI Developer Assistant, a privacy‑first code‑assistant and orchestrator that can run fully on your own hardware.

The goal is to lower the barrier between “I have an idea for an AI system” and “I have a running prototype on my GPU”. From data generation, through training, to a chat‑style UI – everything lives in the same workspace.
