Deployment & Ops

Local quickstart

  1. Clone BuildAI and pull submodules:
    git clone --recurse-submodules https://github.com/DebelToni/BuildAI.git
  2. Create a Python 3.11 (or newer) virtual environment and install:
    pip install -r BuildAI/requirements.txt
  3. Spin up the UI + server stack:
    docker compose -f docker-compose.gpu.yml up -d
  4. Open localhost:7860 to chat with the model.

GPU cloud nodes (RunPod)

The terra/ wrapper gives you a single command OTP deploy:

cd SUPER-GIANT/terra
./deploy-runpod.sh --instance A6000 --region eu-central-1

A GitHub Actions workflow automatically builds and pushes the Docker images whenever main is updated, so you can roll out a new build with terraform apply in seconds.
