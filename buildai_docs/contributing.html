Contributing

Patches, issues, and feature requests are very welcome – BuildAI is still early and moving fast.

Workflow

  1. Fork and create a topic branch (git checkout -b feat/my‑idea).
  2. Pre‑commit checks: ruff . && pytest
  3. Open a PR against main with a clear summary.

Code Style

  • Blackened, Ruff‑linted Python 3.11.
  • Type hints everywhere (PEP 484).
  • Limit top‑level symbols in __init__.py; prefer explicit imports.

Community

Join the GitHub discussions board or the #buildai Discord channel to chat about the roadmap, bugs, and research ideas.
